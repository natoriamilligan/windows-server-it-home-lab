# Create and Manage Active Directory 

## Objective
Set up Active Directory, establish domain, and create accounts.

## Environment
- Microsoft Active Directory Domain Services
- Active Directory Users and Computers

## Tasks Completed
- Installed Active Directory
- Created domain controller for the server to manage the directory
- Created users from a copy instead of manually
- Create IT organizational unit and moved the helpdesk user to it 

## Troubleshooting
- The local admin account was not on the domain and did not have access to Users and Computers. I needed to create an account on the domain to be able to access Users and Computers.
